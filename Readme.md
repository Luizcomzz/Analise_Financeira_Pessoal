## Projeto de Organização Financeira

# Motivação:
Esse projeto surgiu devido a crescente número de pessoas individadas, que mesmo fazendo anotações dos dados, ainda continuam sem conseguir se organizar financeiramente. 

# Objetivo:
Criar um sistema que resitre os dados financeiros, que gere relatórios, indentifique padrões e ajude a tomar decisão 

# Fluxo: (csv -> Python -> Power BI)
o programa vai receber uma planilha ja elaborada anteriormente
Será feita a limpeza dos dados utilizando Python
Apresentação dos resultados com o Power BI

# Metodologia 
* 1º  Dados
Poderia criar uma tabela nova, mas ja tenho uma que utilizo para controle 
* 2º Limpeza do dados e associar uma descrição o id para organizar em categoria 
* 3º Criar tabelas com SQL para implementar consultas 
* 4º Insights a partir da analise dos dados 
* 5º Apresentação de Dashboard: Grafico de gastos; categorias; KPI; filtros
